## How posts work

Each post is a Markdown file in `content/writing/`. The file name becomes the URL, so `hello-world.md` lives at `/writing/hello-world`.

The block at the top sets the title, date, and an optional one-line summary. Everything below it is regular Markdown: headings, lists, links, `inline code`, and code blocks.

```ts
const greeting = "hello, world";
```

> Blockquotes work too.
